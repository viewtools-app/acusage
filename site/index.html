open source · MIT · offline

Know which account spent your AI tokens.

acusage reads the local logs of Claude Code, Codex, Antigravity and Gemini CLI and reports tokens and API value per account, agent, model, day and session. One Rust binary. No network, no writes.

Get started GitHub
npx acusage
or install the binary (macOS, Linux)
curl -LsSf https://github.com/viewtools-app/acusage/releases/latest/download/acusage-installer.sh | sh

03 privacy
  • no network. The binary opens no sockets. Prices come from a built-in table, an embedded LiteLLM snapshot and your config.
  • no writes. It never creates, changes, locks or deletes a file. A test runs it against read-only logs.
  • no credentials. It never reads token or auth files; from the account file it reads only the fields used for labels.

Try it in five seconds.

npx acusage
reads your local logs, prints a table, touches nothing
